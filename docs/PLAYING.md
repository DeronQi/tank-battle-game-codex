# 玩法、道具与关卡工坊

## 开局与续关

开始画面可选择单人、双人协作或 AI 演示，以及轻松、标准、精英三档敌军强度。

作战画面只保留战场与状态栏。顶部「开始画面」或战场配置按钮会暂停当前战斗，可选择开始新战役或返回继续。帮助与工坊弹窗会暂停战斗，关闭后恢复原来的状态。全屏按钮将战场和状态栏一起放大。

| 结果 | 行为 |
|---|---|
| 胜利 | 关卡编号加一，随机生成下一张地图，保留得分、生命和火力；阵亡队员至少以一条生命重新加入 |
| 失败 | 重试当前编号与原始地图，恢复本关开始时的得分、生命和火力 |
| AI 演示 | 约 3.5 秒后自动执行对应的续关或重试 |

失败重试时，敌军行动重新随机，避免完全重复同一条失败路线。

## 敌军

| 类型 | 装甲 | 特点 | 击破得分 |
|---|---:|---|---:|
| 侦察型 | 1 | 常规移动和火力 | 100 |
| 突击型 | 1 | 快速移动 | 200 |
| 速射型 | 2 | 更快开火 | 300 |
| 重装型 | 4 | 高装甲 | 400 |

闪烁的敌人携带补给，击破后会掉落道具。战场也会定时出现随机补给。

## 七种道具

移动到道具附近即可拾取，每次拾取加 50 分。

| 道具 | 效果 |
|---|---|
| ★ 火力升级 | 最高 Lv.3；提高炮速，Lv.2 增强伤害，Lv.3 可破坏钢墙 |
| ◇ 无敌护盾 | 12 秒免疫伤害 |
| ✹ 全屏轰炸 | 摧毁当前场上的敌军坦克；不移除已经发射的炮弹 |
| ♥ 额外生命 | 增加一条生命，上限 6 条 |
| ◷ 时间冻结 | 冻结敌军坦克 8 秒；已发射的炮弹仍会运动 |
| ▣ 基地加固 | 修复基地周围护墙，提供约 20 秒钢铁防护 |
| ϟ 极速突袭 | 12 秒移动与开火加速 |

中弹会失去一条生命和火力升级；仍有生命时会复活，并获得短暂保护。

## 地形

| 编号 | 地形 | 规则 |
|---|---|---|
| 0 | 空地 | 可通行 |
| 1 | 砖墙 | 阻挡坦克和炮弹，可破坏 |
| 2 | 钢墙 | 阻挡坦克和炮弹，玩家 Lv.3 炮弹可破坏 |
| 3 | 水域 | 阻挡坦克，炮弹可穿过 |
| 4 | 树林 | 可通行，提供视觉遮挡 |
| 5 | 冰面 | 可通行，增加移动速度 |

随机地图先按废墟、林地、水域或冰原的比例生成地形，再修复局部连通性。出生区、基地与护墙保留，其他位置自然变化；不固定清空整行、整列，也不刻意避免直线通道。

## 关卡工坊

1. 打开「关卡工坊」，选择地形画笔。
2. 点击或拖动绘制；右键擦除。可撤销、清空或随机生成。
3. 给地图命名并保存。地图需通过出生区与路线连通性校验。
4. 点击「保存并开始作战」，或在开始画面选择自定义关卡。

出生区和基地本体不能编辑。砖墙可通过射击打开，钢墙和水域不能将出生点封死。自定义地图用于战役第一关；失败重试仍使用原地图，胜利后进入随机下一关。

## 导入导出

使用工坊按钮导出 JSON，即可备份或分享地图；导入上限 64 KB，格式版本为 1。

```json
{
  "format": "steel-front",
  "version": 1,
  "name": "城市防线",
  "tiles": [[0, 1, 2, 3, 4, 5]]
}
```

此处 `tiles` 仅示意地形编号，实际必须是完整的 **26 行 × 26 列**整数数组。长期保存应使用导出文件；算法更新后，同一个种子不保证得到旧版本的地形。

## 设备与本地数据

双人是同设备、同键盘协作。不同键盘的多键同时按下能力存在差异。移动端提供 P1 触控操作，双人建议使用桌面键盘。

最高分、音效开关和一张已保存地图只保留在当前浏览器；没有账号和云端同步。切换浏览器、端口或清除站点数据，会使用不同或新的本地记录。
